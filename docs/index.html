Speed did not waive the checks

What held

  • 4/4 fast-sheet labelled spot-check
  • 7/7 option-order rotations
  • 5/5 deterministic distributions
  • 4/5 decisions match the slow path

What did not

  • The sheet path reads retry_risk as 1.08 where the full prompt reads 3.00—low risk versus high risk.
  • A one-token pointer reached 27 ms—and collapsed accuracy to 1/4.
  • Long-suffix batching was slower than serial.
  • The full-prompt spot-check is 3/4, not 4/4.
  • Raw softmax remains uncalibrated.
  • The model still wrongly recommends an unchanged retry.
Not Jev. This reproduces Jev's typed interface and no-generation inference shape. It does not reproduce TypeSafe's model, RLCD training, calibration, or hosted infrastructure.

This is now an ecosystem, not one trick.

The easy part has become reproducible: many projects can turn a language model into a bounded decision function. The frontier is separating model quality, probability quality, and shared-state execution.

trained decision models
Jev · Laya · Kev · Mapika Decider
Train the representation/readout for decisions instead of leaving a chat model unchanged. This is where calibration, generalization, and explicit question isolation can become model properties.
inference adapters
OpenJev · SemIf · openjev-sglang
Reuse ordinary LMs, restrict the answer space, and read logits instead of prose. This establishes that “stop generating and choose” is useful engineering, but no longer sufficient novelty by itself.
probability quality
AnyJev · Kev · trained Decider/Jev-style systems
Debias option/label effects, fit calibration, or train calibrated heads. Raw restricted softmax is a model-relative score until evidence shows otherwise.
parallel architectures
djev / DiffusionGemma
Use diffusion-style answer slots rather than ordinary autoregressive continuation, making simultaneous bounded outputs a native architectural possibility.
shared-state systems
vLLM prefix caching · Hydragen · DeFT
The broader inference-systems literature already asks how to reuse expensive prefixes and branch efficiently. The decision-model question adds a semantic constraint: branches must stay independent.
this repo
Gemma System One · Rust · Candle · exact legal-label logits
Research target: maximize many-question throughput while measuring whether optimization changes the decision distribution. The production API shares only the state prefix; the faster packed-sheet path is retained as an explicit semantic-drift experiment.
Current thesis: the restricted-logit trick is commodity. The harder problem is one expensive state → many runtime-defined decisions, while keeping each branch semantically isolated and its probabilities empirically trustworthy.

Long-form map: decision-model landscape. Research plan: semantic isolation.
